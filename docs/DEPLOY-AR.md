# رفع الموقع على الإنترنت — مسار مجاني بالكامل

دليل خطوة بخطوة لتشغيل الموقع ولوحة التحكم على الإنترنت **بدون أي دفع**.

| الخدمة | الدور | التكلفة |
| --- | --- | --- |
| GitHub | الكود | مجاني |
| Supabase (Free) | قاعدة البيانات + تخزين الصور | مجاني |
| Vercel (Hobby) | استضافة الموقع | مجاني |
| رابط `اسمك.vercel.app` | عنوان الموقع | مجاني |

**الإجمالي: صفر.** الدومين المخصص (`nedalelabid.com`) هو الشيء الوحيد المدفوع،
وهو **اختياري تمامًا** — الموقع يشتغل ويتشارك برابط Vercel المجاني.

> **ليه قاعدة بيانات أصلًا؟** لأن ملفات Vercel مؤقتة: أي مشروع أو صورة تضيفها من
> اللوحة تختفي مع أول إعادة نشر. Supabase تحفظ كل شيء بشكل دائم — وهي مجانية.

---

## 1. Supabase — قاعدة البيانات (٥ دقائق)

1. ادخل [supabase.com](https://supabase.com) → **Start your project** → سجّل بحساب
   GitHub.
2. **New project** → اسم المشروع مثلًا `nedal-portfolio` → اختر **كلمة مرور قوية
   لقاعدة البيانات** (احفظها) → اختر أقرب منطقة (Frankfurt أو Bahrain) →
   **Create new project** وانتظر دقيقة.
3. من القائمة اليسرى: **SQL Editor** → **New query**.
4. افتح ملف `supabase/schema.sql` من المشروع، **انسخ محتواه كاملًا** والصقه في
   المحرر → اضغط **Run**. المفروض يظهر `Success`. (الملف آمن لو شغّلته أكثر من
   مرة — لا يمسح أي بيانات.)
5. من **Project Settings → API** انسخ قيمتين:
   - **Project URL** → ستضعها في `NEXT_PUBLIC_SUPABASE_URL`
   - **service_role** (اضغط Reveal) → ستضعها في `SUPABASE_SERVICE_ROLE_KEY`

> مفتاح `service_role` سري ويُستخدم على الخادم فقط — لا تضعه في أي مكان عام ولا
> ترسله لأحد.

---

## 2. جهّز بيانات دخول اللوحة

تحتاج ثلاث قيم:

| المتغير | القيمة |
| --- | --- |
| `ADMIN_EMAIL` | بريدك، مثلًا `nedotito74@gmail.com` |
| `ADMIN_PASSWORD` أو `ADMIN_PASSWORD_HASH` | كلمة مرور الدخول للوحة |
| `ADMIN_SESSION_SECRET` | نص عشوائي طويل (٣٢ حرفًا فأكثر) |

**الطريقة الأسهل (بدون تنصيب أي شيء):** استخدم `ADMIN_PASSWORD` بكلمة مرور قوية،
و`ADMIN_SESSION_SECRET` بنص عشوائي طويل (أي مولّد كلمات مرور، أو اضرب على
الكيبورد ٤٠ حرفًا عشوائيًا). القيم تُحفظ مشفّرة داخل Vercel ولا تظهر في الكود.

**الطريقة الأكثر أمانًا (لو عندك Node على جهازك):**

```bash
npm run admin:hash -- "كلمة-المرور-التي-تريدها"
```

ينتج لك سطرين جاهزين: `ADMIN_PASSWORD_HASH=...` و `ADMIN_SESSION_SECRET=...`.
عندها لا تضع `ADMIN_PASSWORD` إطلاقًا.

---

## 3. Vercel — النشر (٥ دقائق)

1. ادخل [vercel.com](https://vercel.com) → **Sign up** بحساب GitHub → اختر خطة
   **Hobby** (المجانية).
2. **Add New… → Project** → اختر مستودع `fawasel` → **Import**.
3. قبل الضغط على Deploy، افتح **Environment Variables** وأضف:

   | الاسم | القيمة |
   | --- | --- |
   | `NEXT_PUBLIC_SUPABASE_URL` | Project URL من Supabase |
   | `SUPABASE_SERVICE_ROLE_KEY` | مفتاح service_role |
   | `ADMIN_EMAIL` | بريدك |
   | `ADMIN_PASSWORD` *(أو `ADMIN_PASSWORD_HASH`)* | كلمة المرور |
   | `ADMIN_SESSION_SECRET` | النص العشوائي |
   | `NEXT_PUBLIC_SITE_URL` | `https://اسم-المشروع.vercel.app` |

   > لا تعرف رابط Vercel قبل النشر؟ انشر أولًا، ثم ارجع وأضف
   > `NEXT_PUBLIC_SITE_URL` بالرابط الحقيقي واضغط **Redeploy**.

4. **الفرع (مهم):** الكود الحالي على فرع `claude/new-session-weufaa`. إما تضبط في
   **Settings → Git → Production Branch** هذا الفرع، أو تدمجه في `main` وتترك
   الإعداد الافتراضي.
5. اضغط **Deploy** وانتظر دقيقتين. يظهر لك الرابط: `https://....vercel.app`.

---

## 4. أول دخول للّوحة

1. افتح `https://رابطك.vercel.app/admin`.
2. سجّل الدخول ببريدك وكلمة المرور اللتين وضعتهما في Vercel.
3. قاعدة البيانات جديدة وفارغة، لذلك ستجد في الأعلى زر **«تحميل المحتوى
   المبدئي»** — اضغطه مرة واحدة. سيملأ: نصوص الموقع، الخدمات الـ16، المهارات،
   العملاء الخمسة، الأرقام السبعة، روابط التواصل، وقائمة التنقل.
4. **مكتبة الوسائط** → ارفع صورتك الشخصية وشعارات العملاء (تُحفظ في تخزين
   Supabase مباشرة).
5. **الإعدادات → الصور** → اختر صورة الهيرو.
6. ابدأ بإضافة المشاريع والمقالات.

---

## 5. شارك الرابط

أرسل `https://رابطك.vercel.app` لأي شخص — الموقع عام ويعمل فورًا.
لوحة التحكم على `/admin` محمية بكلمة المرور، ومستبعدة من محركات البحث.

---

## 6. التعديلات بعد النشر

- **تعديل محتوى** (نصوص، خدمات، مشاريع، صور): من اللوحة مباشرة — يظهر فورًا بدون
  إعادة نشر.
- **تعديل تصميم أو كود**: أي `git push` على فرع الإنتاج يجعل Vercel يبني وينشر
  النسخة الجديدة تلقائيًا خلال دقيقتين.

---

## 7. أشياء يجب معرفتها عن الباقات المجانية

- **Supabase Free**: 500 ميجابايت قاعدة بيانات + 1 جيجابايت تخزين صور — أكثر من
  كافٍ لموقع شخصي. المشروع **يُوقَف مؤقتًا بعد نحو أسبوع بدون أي نشاط**، وتعيده
  بضغطة **Restore** من لوحة Supabase. أي زيارة للموقع تُحسب نشاطًا، فطالما
  الموقع يُزار لن يتوقف.
- **Vercel Hobby**: مجاني وشروطه للاستخدام **الشخصي**. موقع شخصي تعريفي مناسب
  تمامًا؛ ولو تحوّل لاحقًا لموقع شركة فالخيارات: ترقية Vercel (مدفوعة) أو النقل
  إلى **Cloudflare Pages** أو **Netlify** — الاثنان لهما باقة مجانية تسمح
  بالاستخدام التجاري، ونفس الكود يعمل عليهما.
- **النسخ الاحتياطي**: من Supabase → **Database → Backups** يمكنك تنزيل نسخة من
  بياناتك في أي وقت.

## 8. حل المشاكل الشائعة

| المشكلة | الحل |
| --- | --- |
| اللوحة تقول «للقراءة فقط» أو التعديلات لا تُحفظ | متغيرا Supabase غير مضبوطين في Vercel. أضِفهما ثم **Redeploy**. |
| «بيانات دخول غير صحيحة» | راجع `ADMIN_EMAIL` و`ADMIN_PASSWORD`، وتأكد أنك ضبطت `ADMIN_SESSION_SECRET` (٣٢ حرفًا فأكثر) ثم أعد النشر. |
| الموقع فارغ من الخدمات والعملاء | لم تضغط **«تحميل المحتوى المبدئي»** في اللوحة. |
| الصور المرفوعة لا تظهر | تأكد أن ملف `schema.sql` عمل بنجاح (هو الذي ينشئ مخزن `media`)، وأن `SUPABASE_SERVICE_ROLE_KEY` صحيح. |
| صفحة المشروع تعطي 404 | المشروع غير منشور: افتحه في اللوحة وفعّل **Published**. |
