# دليل لوحة التحكم — NEDAL ELABID

دليل عملي بالعربية لكل ما يمكن التحكم فيه من لوحة التحكم، بدون أي تعديل على الكود.

---

## 1. تشغيل المشروع على جهازك

```bash
npm install
npm run dev
```

ثم افتح: <http://localhost:3000>

لوحة التحكم: <http://localhost:3000/admin>

**بيانات الدخول أثناء التطوير المحلي:**

```
البريد:      admin@nedal.local
كلمة المرور: nedal-dev-admin
```

> هذه البيانات تعمل محليًا فقط، ويرفضها النظام تلقائيًا عند النشر على الإنترنت
> (وضع production)، حتى لا يستطيع أحد الدخول بها على الموقع الحقيقي.

**لإنشاء بيانات دخول حقيقية قبل النشر:**

```bash
npm run admin:hash -- "كلمة-المرور-التي-تريدها"
```

سيطبع لك سطرين، ضعهما في متغيرات البيئة مع بريدك:

```
ADMIN_EMAIL=nedotito74@gmail.com
ADMIN_PASSWORD_HASH=scrypt:...
ADMIN_SESSION_SECRET=...
```

## 2. لغة لوحة التحكم (عربي / إنجليزي)

في الشريط العلوي للوحة يوجد زر لغة 🌐 — اضغطه لتتحوّل اللوحة بالكامل إلى العربية
باتجاه RTL: القائمة الجانبية، أسماء الأقسام، أسماء الحقول، الأزرار، والرسائل.

- اختيارك محفوظ في كوكيز خاص باللوحة (`nedal_admin_locale`)، ويبقى في كل زياراتك.
- **لغة اللوحة منفصلة تمامًا عن لغة الموقع العام**: تقدر تدير الموقع بالعربية
  بينما الزائر يرى الموقع بالإنجليزية أو العكس.
- حقول المحتوى تبقى مزدوجة دائمًا (EN + AR) مهما كانت لغة اللوحة، لأنك تحرّر
  اللغتين معًا.

---

## 3. شكل لوحة التحكم

القائمة الجانبية مقسّمة إلى ثلاث مجموعات:

| المجموعة | العناصر |
| --- | --- |
| **Overview** | Dashboard — نظرة عامة على كل المحتوى وآخر طلبات العملاء |
| **Content** | Projects · Clients · Services · Skills · Tools · Experience · Testimonials · Metrics |
| **Site** | Hero & copy · Media library · Navigation · Social links · Inquiries · Settings |

في الشريط العلوي: بريد المستخدم، نوع قاعدة البيانات المستخدمة (`json` أو
`supabase`)، زر **View site** لفتح الموقع، وزر **Sign out** للخروج.

---

## 4. الأزرار المشتركة في كل الجداول

في كل قائمة (المشاريع، العملاء، الخدمات…) تجد في آخر كل صف:

| الزر | الوظيفة |
| --- | --- |
| ⬆ / ⬇ | تغيير ترتيب ظهور العنصر في الموقع |
| 👁 / 🚫 | نشر أو إخفاء العنصر من الموقع مباشرة |
| ⧉ | نسخ العنصر (تُنشأ نسخة كمسودة غير منشورة) |
| 🗑 | حذف نهائي (يطلب تأكيدًا أولًا) |

وفوق الجدول: مربع **بحث**، وفلاتر **All / Published / Draft**، وزر
**New …** لإضافة عنصر جديد.

داخل صفحة التعديل يوجد شريط ثابت في الأسفل فيه زر **Save**، وزر **Preview**
(للمشاريع) لمعاينة الصفحة قبل النشر، وزر **Delete** في الأعلى.

> كل حقل نصّي يظهر مرتين: **EN** للإنجليزية و **AR** للعربية. لو تركت لغة فارغة،
> يعرض الموقع اللغة الأخرى تلقائيًا بدلًا من ترك فراغ.

## 5. المشاريع (Projects) — أهم قسم

`Projects → New project`

الحقول:

- **Project name / Slug** — الاسم، والرابط الذي يظهر في `/projects/الرابط`.
  اتركه فارغًا وسيُولَّد من الاسم الإنجليزي تلقائيًا، ولن يتكرر أبدًا.
- **Client / Industry / Year / Category / Tags** — بيانات البطاقة والفلترة.
- **Short summary** — الملخص الذي يظهر في بطاقة المشروع.
- **The challenge · Business objective · Strategic approach · Creative
  direction · Execution · Results** — فصول دراسة الحالة، تظهر بالترتيب في صفحة
  المشروع، وأي فصل تتركه فارغًا لا يظهر إطلاقًا.
- **Key metrics** — أرقام النتائج (مثال: `Cost per lead` → `-38%`). زر
  **Add metric** يضيف صفًا جديدًا.
- **Services delivered** — الخدمات المرتبطة بالمشروع (اختيار متعدد).
- **Cover image** — صورة الغلاف: اكتب رابطًا، أو اختر من **Library**، أو ارفع
  ملفًا مباشرة بزر **Upload**.
- **Gallery** — رابط صورة في كل سطر.
- **Video embed URL** — رابط تضمين فيديو (YouTube/Vimeo embed).
- **Featured** — يظهر ضمن الأعمال المختارة في الصفحة الرئيسية.
- **Pinned** — يُثبَّت في أول القائمة.
- **Published** — منشور أم مسودة.
- **SEO title / SEO description** — بيانات محركات البحث لهذه الصفحة تحديدًا.

**الدورة الكاملة:** أنشئ المشروع → ارفع صوره → فعّل **Published** → **Save**،
وسيظهر فورًا في `/projects` وفي صفحته الخاصة، وفي الرئيسية لو كان **Featured**.
وعند إلغاء النشر تعود صفحته 404 مباشرة.

## 6. المقالات (Articles) — قسم جديد

`Articles → New article`

- **العنوان / الرابط** — الرابط يظهر في `/articles/الرابط`، ويُولَّد من العنوان
  تلقائيًا لو تركته فارغًا.
- **وصف قصير** — يظهر في بطاقة المقال.
- **نص المقال** — نص عادي: اترك **سطرًا فارغًا** بين كل فقرة وأخرى، وأي سطر يبدأ
  بـ `## ` يتحوّل إلى عنوان فرعي داخل المقال.
- **صورة الغلاف · التصنيف · الكاتب · التاريخ**.
- **مميّز** — المقالات المميّزة هي التي تظهر في الصفحة الرئيسية (حتى ثلاثة).
- **منشور · الترتيب · عنوان ووصف SEO**.

الصفحات: `/articles` لكل المقالات، و`/articles/الرابط` لصفحة المقال الواحد مع
مقالات ذات صلة ودعوة لبدء مشروع.

## 7. باقي أقسام المحتوى

- **Clients** — الاسم، الشعار، القطاع، الوصف، الموقع الإلكتروني، مميّز، الترتيب.
  (العملاء الخمسة المعروفون مضافون بالفعل بدون شعارات — ارفع الشعارات وقتما تتوفر.)
- **Services** — 16 خدمة جاهزة من ملف العلامة، مع وصف قصير وطويل وتصنيف وترتيب.
- **Skills** — مصفوفة القدرات مقسّمة إلى تصنيفات (Strategy / Performance /
  Creative / Video / Digital / AI). التصنيف يُكتب في حقل **Category**، وأي تصنيف
  جديد تكتبه ينشئ مجموعة جديدة في الموقع تلقائيًا.
- **Tools** — شارات الأدوات (فارغة حاليًا؛ أضف ما تستخدمه فعليًا).
- **Experience** — الخط الزمني المهني: الشركة، المسمى، التواريخ، المكان، الوصف،
  الإنجازات، المهارات. (فارغ حاليًا — لم يتم اختراع أي تاريخ وظيفي.)
- **Testimonials** — آراء العملاء: الاسم، المنصب، الشركة، النص، الصورة، المشروع
  المرتبط. (فارغ حتى تدخل آراءً حقيقية.)
- **Metrics** — الأرقام (سنوات الخبرة، العملاء، العلامات، الحملات، الإنفاق
  الإعلاني، العملاء المحتملون، النمو). الخيار **Show in hero** يحدد أي أرقام
  تظهر في الهيرو (تُعرض أول أربعة)، والباقي يظهر في قسم *Marketing Intelligence*.
  الحقول: القيمة الرقمية + بادئة + لاحقة (مثل `+` أو `M+ SAR`).

## 8. Hero & copy — نصوص الموقع

`Site → Hero & copy`

هنا كل كلمة تظهر على الموقع، مجمّعة حسب القسم (Hero، About، Services، Work،
Clients، Experience، Intelligence، Testimonials، Contact، Footer)، بالعربية
والإنجليزية. يشمل ذلك اسمك، المسمى الوظيفي، الجملة التعريفية، فلسفة العمل، نصوص
الأزرار، عناوين الأقسام، ونصوص الحالات الفارغة.

اضغط **Save copy** ليظهر التعديل على الموقع فورًا.

## 9. Media library — الصور

`Site → Media library`

- **Upload files** لرفع صورة أو أكثر (حتى 8 ميجابايت للملف، صيغ الصور المعروفة).
- بدون Supabase تُحفظ الملفات في مجلد `data/uploads` وتُقدَّم عبر الرابط
  `/uploads/...`، ومع Supabase تُحفظ في مخزن الصور الخاص به.
- كل صورة مرفوعة تصبح متاحة داخل أي حقل صورة عبر زر **Library**.
- الحذف يزيل السجل والملف الفعلي معًا.

### كيف تضع صورتك الشخصية في الهيرو

1. **Media library** → **Upload files** → ارفع الصورة الشخصية.
2. **Settings → Imagery** → اختر الصورة في **Hero portrait**.
3. اختياريًا: **Hero spotlight reveal** — صورة ثانية تظهر تحت دائرة الضوء التي
   تتبع مؤشر الماوس فوق الصورة الأساسية.
4. **About portrait** — الصورة الثانية المستخدمة في قسم «نبذة».

> الصور الحالية مؤقتة (Placeholder) لأنه لم يتم إرفاق ملف صورة قابل للحفظ.
> الهيرو مصمّم لصورة سينمائية عالية التباين بملابس سوداء وظلال عميقة.

## 10. Navigation & Social links

- **Navigation** — عناصر القائمة العلوية: النص (عربي/إنجليزي)، الرابط، الترتيب،
  والإظهار. يمكنك إخفاء عنصر بدل حذفه.
- **Social links** — روابط لينكدإن، فيسبوك، إنستغرام، تيك توك، بيهانس، واتساب.
  تظهر في صفحة التواصل وفي الفوتر.

---

## 11. Inquiries — طلبات العملاء

الحقول الإلزامية في النموذج هما **الاسم ورقم الهاتف/الواتساب** فقط، وباقي
الحقول اختيارية حتى لا يتعطّل العميل عن التواصل.

كل رسالة من نموذج «ابدأ مشروعًا» تُحفظ هنا: الاسم، الشركة، البريد، الواتساب،
الخدمة المطلوبة، الميزانية، وتفاصيل المشروع. تظهر أحدث خمس رسائل في الصفحة
الرئيسية للوحة، ويمكن فتح كل رسالة وتعليمها **Handled** بعد الرد عليها.

## 12. Settings — الإعدادات العامة

`Site → Settings`

- **SEO & sharing** — عنوان الموقع ووصفه (عربي/إنجليزي)، الكلمات المفتاحية،
  صورة المشاركة (OG image)، والأيقونة.
- **Contact & language** — البريد، رقم الواتساب، واللغة الافتراضية للزائر الجديد.
- **Appearance** — لوني التدرّج (أحمر → برتقالي)، ومؤشر **Visual intensity**
  الذي يتحكم في قوة التوهج والحبيبات والتفاصيل التقنية في كل الموقع.
- **Imagery** — صور الهيرو والنبذة.
- **Homepage sections** — تشغيل/إيقاف أي قسم في الصفحة الرئيسية بمربع اختيار.

## 13. اللغة على الموقع

- زر تبديل اللغة في القائمة العلوية يحفظ اختيار الزائر في كوكيز.
- الزائر الجديد يرى اللغة الافتراضية المحددة في **Settings**.
- العربية تعمل باتجاه RTL كامل، والإنجليزية LTR.

## 14. النشر على الإنترنت

1. أنشئ مشروعًا على **Supabase**، ونفّذ ملف `supabase/schema.sql` في محرّر SQL.
   (يُنشئ الجداول، الحماية، وصلاحيات القراءة، ومخزن الصور.)
2. اضبط متغيرات البيئة:
   - `NEXT_PUBLIC_SUPABASE_URL` و `SUPABASE_SERVICE_ROLE_KEY`
   - `ADMIN_EMAIL` و `ADMIN_PASSWORD_HASH` و `ADMIN_SESSION_SECRET`
   - `NEXT_PUBLIC_SITE_URL`
3. `npm run build` ثم `npm start` (أو انشر على أي استضافة تدعم Next.js).
4. ادخل `/admin`، ارفع صورتك، وانشر أول دراسة حالة.

> بدون Supabase يعمل الموقع على ملف `data/cms.json` — ممتاز للتجربة المحلية،
> لكنه لا يصلح للاستضافات السحابية التي لا تسمح بالكتابة على الملفات.

## 15. ترتيب الصفحة الرئيسية (بعد تحديث V2)

```
01 الهيرو   02 نبذة   03 الخدمات (سلايدر)   04 أعمالي
05 المهارات   06 أرقام التسويق (متحرك)   07 العملاء (شريط لوجوهات)
08 آراء العملاء   09 مقالاتي   10 ابدأ مشروعًا   11 الفوتر
```

**لإخفاء أي قسم نهائيًا** (المهارات مثلًا): **الإعدادات → أقسام الصفحة الرئيسية**
→ أزل علامة القسم → **حفظ**. القسم يختفي فورًا من الصفحة الرئيسية ومن صفحة
«نبذة» أيضًا، وبياناته تبقى محفوظة في اللوحة لو رجعت تفعّله لاحقًا.

**أقسام أُزيلت من الموقع العام:** «المسار المهني» و«الأدوات». القسمان ما زالا
موجودين في لوحة التحكم لإدارة البيانات، لكنهما لا يظهران للزائر.

**الألوان الجديدة:** أسود `#000000` + أبيض `#FFFFFF` + لايم `#BEF532`. اللون
اللايم هو لون التمييز (الأزرار، الحالات النشطة، الأرقام)، ويمكن تغييره من
**الإعدادات → المظهر**.

## 16. ملاحظة مهمة عن المحتوى

لم يتم اختراع أي مشروع أو نتيجة أو رأي عميل أو تاريخ وظيفي. الأقسام التالية تبدأ
فارغة وتعرض «حالة فارغة» أنيقة حتى تُدخل بيانات حقيقية:

**Projects · Articles · Experience · Testimonials · Tools**

أما الخدمات والمهارات والعملاء الخمسة والأرقام السبعة وروابط التواصل والنصوص،
فهي مضافة كما وردت في ملف العلامة، وكلها قابلة للتعديل من اللوحة.
